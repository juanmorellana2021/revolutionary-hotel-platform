## ✅ **Option 3: Install Git CLI (Advanced)**

### **Download Git**
1. Go to: https://git-scm.com/download/win
2. Download Git for Windows
3. Install with default settings
4. Restart your terminal/VS Code

### **Initialize Repository**
```powershell
# Navigate to project directory
cd C:\xampp\htdocs\hotel-booking-system

# Initialize git repository
git init

# Add all files
git add .

# Create initial commit
git commit -m "Initial commit - Revolutionary hotel management system with dual currency"

# Add GitHub remote (replace YOUR_USERNAME with your GitHub username)
git remote add origin https://github.com/YOUR_USERNAME/revolutionary-hotel-management.git

# Push to GitHub
git branch -M main
git push -u origin main
```
