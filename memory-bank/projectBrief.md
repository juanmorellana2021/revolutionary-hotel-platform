## Project Summary

A comprehensive hotel management system with room management, public booking, accounting dashboard, Aini Coin rewards ecosystem, WhatsApp integration for customer communication, and multi-user role management (admin, manager, accounting).



## Goals

- Streamline hotel operations with digital room management
- Enable online public booking system
- Integrate WhatsApp for customer service automation
- Implement Aini Coin rewards system for customer loyalty
- Provide role-based dashboards for staff
- Track accounting and financial operations



## Constraints

- Using XAMPP/PHP stack
- MySQL database backend
- Multiple file versions indicate ongoing optimization
- Integration with WhatsApp API
