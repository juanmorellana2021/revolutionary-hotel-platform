Results in professional-grade codebase ready for team collaboration and long-term maintenance. |

| 2025-11-10 | Foreign Key CASCADE for Automatic Cleanup | Used ON DELETE CASCADE for dependent child records: experience → partner (delete experiences if partner deleted), booking → experience (delete bookings if experience deleted). Used ON DELETE SET NULL for reviews (keep review if booking deleted). Prevents orphaned records automatically. Maintains referential integrity at database level. Trade-off: Can't soft-delete without detaching FKs. Performance: Indexed foreign keys required. Simplifies application code (no manual cascade logic). |
| 2025-11-10 | FULLTEXT Search Index for Natural Language Queries | Added FULLTEXT idx_search (title, description) on aini_experiences table. Requires InnoDB MySQL 5.6+. Minimum word length: 4 chars default (configure ft_min_word_len). Combine with traditional filters for powerful search. Example: "machu picchu sunrise trek" finds relevant experiences even if words in different order. |
